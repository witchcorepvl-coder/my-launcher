# PVL Craft Launcher

Лаунчер сервера **PVL Craft**. Игрок запускает его, вводит ник и нажимает **«Играть»**. Остальное лаунчер делает сам:

- **сам выбирает сборку по компьютеру**: видеокарта NVIDIA и больше 8 ГБ памяти → FULL, иначе → LITE (игрок может поменять в ⚙ Настройках);
- скачивает Java 21, сборку и файлы Minecraft;
- запускает игру и **сразу заходит на сервер**;
- показывает новости и сколько игроков онлайн;
- показывает 3D-скин игрока по нику (берёт его у Mojang).

Новостями, сплэшами, адресом сервера и ссылками на сборки управляют **через файл `config.json` на GitHub**. Пересобирать лаунчер для этого не нужно.

## 1. Быстрый старт в IntelliJ IDEA

1. Поставь **Node.js LTS** с [nodejs.org](https://nodejs.org).
2. В IntelliJ: **File → Open** → выбери папку `pvl-launcher`.
3. Справа вверху в списке запусков выбери **«Установить зависимости (npm install)»** и нажми ▶. Это нужно один раз (и после изменения `package.json`).
4. Выбери **«▶ Запустить лаунчер»** и нажми ▶ — откроется лаунчер.

Если списка запусков нет — в терминале IntelliJ:
```
npm install
npm start
```

## 2. Управление через config.json

Файл лежит в публичном репозитории **`witchcorepvl-coder/pvl-launcher-data`** (ветка `main`).
Чтобы что-то поменять: открой файл на github.com → карандаш ✏️ → правка → **Commit changes**.
Игроки увидят изменения при следующем запуске лаунчера (обычно через 1–5 минут).

> ⚠️ Перед сохранением проверь файл на **[jsonlint.com](https://jsonlint.com)**. Если JSON сломан, лаунчер покажет последнюю рабочую версию (с пометкой «Сохранённые»), но новые изменения не применятся.

Полный пример — файл `config.json` в этом проекте. Структура:

```json
{
  "news": "текст новостей",
  "splashes": ["сплэш 1", "сплэш 2"],
  "server_ip": "anfisa.proximamp.com:27292",
  "auto_select": { "min_ram_gb": 8, "gpu": ["nvidia"] },
  "builds": {
    "full": { "version": "4.8", "ram": 6144, "url": "…", "sources": ["…"] },
    "lite": { "version": "4.8", "ram": 4096, "url": "…", "sources": ["…"] }
  }
}
```

### Новости — `news`

Одна строка с текстом. Правила:

| Что нужно | Как написать |
|---|---|
| Новая строка | `\n` |
| Пустая строка (абзац) | `\n\n` |
| Жирный | `<b>текст</b>` |
| Курсив | `<i>текст</i>` |
| Цвет | `<span style=\"color:#55ff55\">текст</span>` |
| Ссылка (откроется в браузере) | `<a href=\"https://…\">текст</a>` |
| Кавычки внутри текста | `\"` |
| Эмодзи | просто вставь: 🎁 ⚠️ 🐾 |

Можно также: `<u>`, `<small>`, `<code>`, `<hr>` (линия), `<ul><li>…</li></ul>` (список).
Всё остальное (картинки, скрипты и т.п.) лаунчер вырезает — это защита.

Блок новостей вмещает примерно **20 строк** (как новость 4.8) без прокрутки. Если текст длиннее — появится прокрутка.

Удобные цвета: зелёный `#55ff55`, оранжевый `#ffaa00`, красный `#ff5555`, голубой `#5fe1ff`, жёлтый `#ffff55`.

### Сплэши — `splashes`

Жёлтые надписи у логотипа (как в Minecraft). Каждый запуск — случайная. Клик по логотипу — новая.

```json
"splashes": ["Крипер сзади!", "Теперь с питомцами!", "Пинг до Барнаула: 2мс!"]
```

Длинные фразы (больше ~30 символов) автоматически показываются мельче.

### Сервер — `server_ip`

```json
"server_ip": "anfisa.proximamp.com:27292"
```

По этому адресу лаунчер показывает онлайн (на экране — только число игроков, сам адрес игроки не видят) и **сразу подключает игрока** после загрузки игры (игрок может выключить это в настройках).

### Сборки — `builds`

Для каждой сборки (`full`, `lite`):

| Поле | Что это |
|---|---|
| `version` | Номер версии сборки. **Поменял → у всех игроков сборка обновится.** Можно любой текст: `"4.8"`, `"5"`, `"2026-11-07"`. |
| `ram` | Сколько памяти (МБ) давать игре по умолчанию. 6144 = 6 ГБ. Игрок может поменять в настройках. Лаунчер сам урежет, если у игрока мало памяти. |
| `url` | Основная ссылка на архив сборки. Лучше не менять без нужды (смена = переустановка у всех со старой версией лаунчера). |
| `sources` | **Откуда качать, по порядку.** Если первое место не отдаёт файл (лимит, блокировка, обрыв) — лаунчер сам берёт следующее. |

Что можно писать в `sources`:

```json
"sources": [
  "https://disk.yandex.ru/d/AbCdEf123",
  { "parts": [
      "https://github.com/witchcorepvl-coder/pvl-launcher-data/releases/download/full-4.8/full.zip.001",
      "https://github.com/witchcorepvl-coder/pvl-launcher-data/releases/download/full-4.8/full.zip.002"
  ] },
  "https://www.dropbox.com/scl/fi/…/full.zip?rlkey=…&dl=1"
]
```

- **Dropbox** — обычная ссылка «Поделиться» (`dl=0` лаунчер сам поменяет на `dl=1`).
- **Яндекс Диск** — обычная ссылка `disk.yandex.ru/d/…` (лаунчер сам получит прямую ссылку через API Яндекса).
- **Google Drive** — ссылка вида `drive.google.com/file/d/…`.
- **Части архива** `{ "parts": [...] }` — для GitHub (там лимит 2 ГБ на файл), см. раздел 3.
- **Прямая ссылка** на `.zip` с любого сайта.

### Автовыбор сборки — `auto_select`

По умолчанию в настройках у игрока стоит **«Авто»**: лаунчер смотрит видеокарту и память компьютера.

- есть видеокарта из списка `gpu` **и** памяти больше `min_ram_gb` → **FULL**;
- иначе → **LITE**.

```json
"auto_select": { "min_ram_gb": 8, "gpu": ["nvidia"] }
```

`gpu` может содержать `"nvidia"`, `"amd"`, `"intel"`, `"apple"`. Например, пустить на FULL ещё и владельцев Radeon с 12+ ГБ:
`{ "min_ram_gb": 12, "gpu": ["nvidia", "amd"] }`. Если поля нет — работает правило по умолчанию (NVIDIA и больше 8 ГБ).

На главном экране игрок не видит ни версию, ни откуда качается сборка — только «Скачиваю сборку · 412 из 1520 МБ».
Выбрать вручную можно в **⚙ Настройки → Версия сборки: Авто / FULL / LITE** — там же написано, что нашёл лаунчер («NVIDIA GeForce RTX 3060 · 16 ГБ памяти») и какая сборка установлена.

### Как выпустить обновление сборки

1. Собери новый архив сборки (`.zip`, внутри папки `mods`, `config`, `versions`, `libraries` и т.д. — как раньше).
2. Залей его **во все места** из `sources` (новые ссылки или замена старых файлов).
3. В `config.json`: обнови ссылки и **подними `version`** (например `"4.8"` → `"4.9"`).
4. Обнови `news` — напиши, что нового.
5. Commit.

Готово: у игроков с включённым автообновлением сборка скачается при следующем нажатии «Играть». Старые моды удалятся (папка `mods` заменяется целиком), а настройки, миры и скриншоты игрока останутся.

> Если заменить архив, но **не поднять `version`**, игроки обновление не получат.

## 3. Где хранить сборки

Рекомендуем **2–3 места сразу** — тогда сборка скачается у всех, даже если одно не работает.

| Где | Плюсы | Минусы |
|---|---|---|
| **Яндекс Диск** | Быстро в России | Популярный файл может попасть под **дневной лимит скачиваний** |
| **GitHub Releases** | **Без лимита трафика**, работает везде | Файл **меньше 2 ГБ** (большой архив режем на части) |
| **Dropbox** | Просто | Бесплатный тариф — лимит трафика в день, в России бывает медленно |

Хороший порядок в `sources`: Яндекс Диск → GitHub → Dropbox.

### GitHub Releases (без лимита трафика)

1. Если архив **больше 2 ГБ** — разрежь его: в **7-Zip** правый клик по архиву → **7-Zip → Разбить файл…** → размер `1900M`. Получатся `full.zip.001`, `full.zip.002`, …
2. В репозитории `pvl-launcher-data` → **Releases → Draft a new release**.
3. Тег: например `full-4.8`. Перетащи файлы (части или целый zip). **Publish release**.
4. Ссылка на файл: `https://github.com/witchcorepvl-coder/pvl-launcher-data/releases/download/<тег>/<имя файла>`.
5. В `sources`: целый файл — просто ссылкой; части — через `{ "parts": [ … ] }` **строго по порядку**.

### Яндекс Диск

Загрузи архив → правый клик → **Поделиться → Скопировать ссылку** → вставь в `sources`.

## 4. Оформление

Все файлы оформления — в папке `assets`. После замены пересобери лаунчер (раздел 5).

| Файл | Что это | Требования |
|---|---|---|
| `assets/background.webm` + `assets/background.mp4` | Фоновое видео | Лаунчер сначала берёт WebM (VP9), если не получится — MP4. Без звука, уже размыто — так лаунчер работает плавно даже на слабых ПК. Если ни одно не играет — будет просто градиент |
| `assets/logo.png` | Логотип (вылетает при запуске) | PNG с прозрачностью, ширина ~900 px |
| `assets/icon.png` | Иконка программы | PNG 1024×1024 |
| `assets/default-skin.png` | Скин по умолчанию (если ник не введён или его нет у Mojang) | PNG 64×64, обычный файл скина Minecraft |
| `assets/music.mp3` | Фоновая музыка (необязательно) | Если файла нет — музыки нет, ползунок скрывается. Музыка затихает, когда игра запущена |
| `assets/fonts/minecraft.ttf` | Шрифт сплэша (необязательно) | Можно взять `mc.ttf` из старого лаунчера и переименовать |
| `assets/sounds/*.mp3` | Свои звуки интерфейса (необязательно) | Имена: `hover`, `tap`, `toggle`, `error`, `success`, `whoosh`, `sparkle`, `pop`, для пасхалки — `love`, `launch`, `boom`, `crackle`. Каких нет — звучат встроенные |

### Как подготовить новое фоновое видео

Сними ролик 20–60 секунд (без интерфейса — F1), затем в терминале (нужен [ffmpeg](https://ffmpeg.org)):

```
ffmpeg -i мое_видео.mp4 -vf "scale=910:-2,fps=30,gblur=sigma=1.8,eq=saturation=1.12" -an -c:v libx264 -profile:v main -pix_fmt yuv420p -crf 26 -movflags +faststart assets/background.mp4
ffmpeg -i assets/background.mp4 -c:v libvpx-vp9 -b:v 0 -crf 40 -row-mt 1 -an assets/background.webm
```

Это уменьшит, слегка размоет (`sigma` — сила размытия: 0 — чётко, 7 — сильно) и сожмёт видео, плюс сделает WebM-копию. Насколько затемнён фон — `src/renderer/styles.css` → `.bg-tint`.

### Сплэши по умолчанию, цвета, тексты

- Сплэши на случай, если `config.json` недоступен: `src/renderer/app.js` → `DEFAULT_SPLASHES`.
- Цвета интерфейса: `src/renderer/styles.css` → блок `:root` (`--cyan`, `--blue` и др.).
- Адрес сервера по умолчанию, ссылки на сборки по умолчанию, папка игры: `src/main/core/env.js`.

## 5. Сборка и раздача

### Автоматически через GitHub (рекомендуется — собирает и Windows, и macOS)

1. Загрузи проект в свой репозиторий (например `my-launcher`):
   ```
   git add .
   git commit -m "Лаунчер 2.0"
   git push
   ```
2. На GitHub в репозитории: **Releases → Draft a new release** → тег `v2.0.0` → **Publish**.
3. Через ~10 минут к релизу прикрепятся файлы:
   - `PavlovskCraft.exe` — Windows (один файл, без установки);
   - `PavlovskCraft-arm64.dmg` — Mac на M1–M4;
   - `PavlovskCraft-x64.dmg` — Mac на Intel.

**Постоянные ссылки для игроков** (всегда ведут на последнюю версию; репозиторий должен быть публичным):
```
https://github.com/<аккаунт>/<репозиторий>/releases/latest/download/PavlovskCraft.exe
https://github.com/<аккаунт>/<репозиторий>/releases/latest/download/PavlovskCraft-arm64.dmg
https://github.com/<аккаунт>/<репозиторий>/releases/latest/download/PavlovskCraft-x64.dmg
```

Вручную сборку можно запустить так: вкладка **Actions → «Сборка лаунчера» → Run workflow** (файлы будут в разделе Artifacts).

### Вручную на Windows

В IntelliJ запусти **«Собрать .exe (Windows)»** (или `npm run dist:win`). Файл появится в `dist/PavlovskCraft.exe`.
Если ошибка `Cannot create symbolic link` — включи **Параметры Windows → Для разработчиков → Режим разработчика** и повтори.

### Что сказать игрокам

**Windows:** скачать `PavlovskCraft.exe` и запустить. Если появится синее окно «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае». Лаунчер попросит права администратора — нажать «Да».

**macOS:** открыть `.dmg`, перетащить PavlovskCraft в «Программы», запустить. Если macOS не даёт открыть — «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

Java, сборку и Minecraft лаунчер скачает сам. Ничего ставить не нужно.

## 6. Частые проблемы игроков

Попроси игрока открыть **⚙ Настройки → Журнал запуска → Скопировать** и прислать текст.
В журнале подробно: какая сборка и почему выбрана, каждый источник и ссылка, ответ сервера (HTTP-код, тип, размер), скорость, повторы, проверка архива, Java, память, итог.

**Полный лог лаунчера** (самое подробное — для тебя): **⚙ → «Папка с логами лаунчера»** → `launcher.log` (прошлый запуск — `launcher.old.log`).
Там дополнительно: железо компьютера (процессор, память, все видеокарты), загрузка `config.json`, ошибки интерфейса, полная команда запуска Java и последние 80 строк игры, если она упала. Лог игры — `pvl_log.txt` в папке игры.

| Где | Путь |
|---|---|
| Лог лаунчера (Windows) | `%APPDATA%\.minecraft_pvl\logs\launcher.log` |
| Лог лаунчера (macOS) | `~/Library/Application Support/.minecraft_pvl/logs/launcher.log` |
| Лог игры | `<папка сборки>/pvl_log.txt`, падения — `crash-reports` |

Если окно лаунчера открылось, но что-то не так с интерфейсом — **F12** открывает инструменты разработчика (вкладка Console), **F5** перезагружает интерфейс. Если интерфейс не смог запуститься совсем, лаунчер покажет окно «Лаунчер не смог запуститься» с текстом ошибки.

| Сообщение | Что делать |
|---|---|
| «Хранилище сборки сейчас не отдаёт архив…» | Все ссылки в `sources` не работают у игрока. Добавь ещё одно место (раздел 3). Игроку — попробовать позже или через VPN |
| «Скачивание постоянно обрывается…» | Плохой интернет. Нажать «Играть» ещё раз — загрузка продолжится с места обрыва |
| «Не хватает места на диске» | Нужно ~2,5 размера архива свободного места |
| «Windows или антивирус не дал лаунчеру записать файл» | Добавить папку `%APPDATA%\.minecraft_pvl` в исключения антивируса |
| «Файлы сборки неполные» | ⚙ Настройки → «Переустановить сборку» |
| Игра закрылась с ошибкой (код …) | Лог игры: ⚙ → «Открыть папку игры» → `pvl_log.txt`, а также папка `crash-reports` |
| Не видно онлайн | Сервер выключен или порт закрыт. Проверь `server_ip` в `config.json` |

Где лежат файлы игрока:
- Windows: `%APPDATA%\.minecraft_pvl` (LITE — в `builds\lite`)
- macOS: `~/Library/Application Support/.minecraft_pvl`

## 7. Устройство проекта

```
pvl-launcher/
├── assets/                 оформление (видео, логотип, иконка, музыка, звуки)
├── src/
│   ├── main/               «движок» (работает в фоне, Node.js)
│   │   ├── main.js         окно и связь с интерфейсом
│   │   ├── preload.js      безопасный мост интерфейс ↔ движок
│   │   └── core/
│   │       ├── env.js       пути, адреса, сборки по умолчанию
│   │       ├── config.js    загрузка config.json с GitHub (+ кэш)
│   │       ├── builds.js    установка/обновление сборок FULL и LITE
│   │       ├── net.js       надёжная загрузка (докачка, зеркала, части, проверка zip)
│   │       ├── java.js      поиск и автоустановка Java 21
│   │       ├── minecraft.js файлы Minecraft (Mojang), библиотеки, ассеты
│   │       ├── launch.js    запуск игры (+ автовход на сервер)
│   │       ├── skins.js     скины по нику (Mojang)
│   │       ├── hardware.js  проверка видеокарты и памяти (автовыбор FULL/LITE)
│   │       ├── logger.js    файл logs/launcher.log
│   │       └── server.js    онлайн сервера (свой пинг + mcstatus.io)
│   └── renderer/           интерфейс
│       ├── index.html
│       ├── styles.css      дизайн (liquid glass)
│       ├── app.js          логика интерфейса
│       ├── guard.js        страж запуска: ошибка на экран и в лог вместо пустого окна

```

Важно при изменениях в коде:
- Параметры запуска `--userType legacy`, `--accessToken 0`, `--uuid` (офлайн UUID) **не менять** — на них завязаны сетевые моды.
- Ванильный `1.21.1.jar` **не добавлять** в classpath — NeoForge подключает Minecraft сам (иначе ошибка `ResolutionException`).
- Папку игры `.minecraft_pvl` не переименовывать — у игроков пропадут установленные сборки.
- В `app.js` весь код обёрнут в `(() => { … })()`. Не выноси `const pvl = …` на верхний уровень: `window.pvl` от preload неудаляемый, и такое объявление роняет весь интерфейс (было причиной пустого окна).
